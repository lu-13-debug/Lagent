Lagent 1.2.1 让桌面端连上云端之后，能用上**你自己电脑上的 CLI Agent**：装好软件登录，本机的 Claude Code、Codex、OpenCode、DSH、Gemini 会出现在账号下，任务在本机执行、过程与结果实时回传。

## 下载与使用

下载 **Lagent-Setup-1.2.1-x64.exe**，双击安装，支持 Windows 10/11 x64，无需另装 Node.js。安装包已预置服务地址 `https://lagent.site`，打开即是登录页，不用手填服务器地址。

## 新增

- 本机执行节点：桌面端连接云端后自动在后台启动，扫描本机已安装的 CLI Agent 并注册到账号下；任务在本机执行，过程与结果回传云端，退出登录或关闭软件后这些 Agent 自动消失。
- Android 手机端外壳 `mobile/android`：WebView 加载 `/m`，用配对码连接云端账号。
- 新增 `deploy/set-domain.sh`：备案域名一条命令切换，自动备份、停用临时配置并申请 HTTPS 证书。
- 安装包默认服务地址改为 `https://lagent.site`，首次启动直接进入登录页。

## 改进

- 登录页左侧介绍改为多 Agent 指挥台的说法，去掉「500 试用额度」「换电脑继续分析」等数据分析版遗留文案。
- 本机 Agent 在界面上的名称、图标与策略沿用原有执行器 id，同一账号连多台电脑时才加节点前缀区分。

## 当前范围

服务端为单实例 SQLite 版本，尚未接入真实支付；安装包未配置商业代码签名，部分安全软件可能在首次运行时拦一次，选择允许即可。版本号统一从 `package.json` 读取。完整变更见仓库 `CHANGELOG.md`。

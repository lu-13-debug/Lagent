# 简洁页面与配色优化设计草案

日期：2026-11-03。用户要求学习MODex简洁页面、保留DataAgent正常版，并学习页面颜色变化。本轮只调查与设计，不修改业务界面。

## 参考与现状

参考路径 D:\codex\Modex-MH-Agent\resources\app\dist\assets。实际读取ConversationPage、conversationLayout、conversationUi、Settings和main的可读前端资源/CSS。参考应用已通过Computer Use打开，但仍停在“核对程序与内置运行环境”页；不能把资源分析当成完整现场交互验收。未登录、修改配色偏好或运行其模型任务。

MODex首页资源体现：居中主问题与任务输入、近期项目列表、按需打开右侧面板；桌面主内容区受max-width约束，避免整屏同时铺满功能。配色有ink/light/warm/green及自定义，侧栏palette按钮循环四个预设；切换整套背景、文字、边框、强调和语义色变量。自定义强调色会计算前景对比度。其墨白不等同于深色模式，不能据此宣称MODex有同样的深色设计。

DataAgent已有AppearanceProvider、按服务/账号存储、简洁/正常、浅色/深色/跟随系统。当前简洁主要是间距和侧栏变化，尚非独立的信息层级；当前颜色以黑白灰为主。

## 简洁版

首页采用三块：短标题/一句引导、居中的分析目标输入与上传入口、最近分析。主内容最大宽约800–880px，左右自然留白，按窄屏收缩。输入区显示已选数据、默认模型与主要动作，不展示整套配置。

输入区只发起现有新建分析向导并预填目标/文件选择，不把用户一句话直接当作付费任务授权，保留最终范围与成本确认。复用现有上传、账号、额度、停止、确认和错误逻辑。

运行后主区展示阶段进度摘要和最新有效结果，详细节点/模型/Skill/用量在抽屉或展开区。报告先呈现摘要、关键指标与主要图表，完整指标、来源、审查记录和方法可展开。重要的失败、待确认、数据缺失、试用额度、演示标记和未审查状态不能因为简洁而隐藏。

数据源/报告/Skill/额度等功能继续可达；仅收纳二级说明，不能把功能从简洁版删除。侧栏保持图标可访问名称、提示和明确当前页，移动端沿用抽屉。原正常版页面组件和布局保留，正常版仍为旧用户默认视图。

## 配色范围（用户已收紧）

仅保留白天、夜间、跟随系统；不新增墨白、海蓝、暖米、松绿或自定义配色，也不引入独立palette设置或配色轮换按钮。沿用现有light/dark/system配置和按账号、服务保存机制，旧用户无需迁移配色字段。

学习MODex的颜色层次与一致性：白天使用明亮主区、稍深侧栏和细分隔线；夜间使用分层深灰背景与清晰文字，避免简单反色。具体色值在DataAgent中重新核对对比度；正常版现有主题效果作为回归基线，不强制改变其视觉风格。

主题统一覆盖页面、侧栏、卡片、浮层、正文、边框、按钮、悬停、选中和焦点。成功/警告/失败保留文字或图标，图表多序列可辨识。简洁/正常视图与明暗设置相互独立，切换不重置任务、模型、筛选或额度。

主题过渡只涉及背景、文字和边线，约150–200ms；prefers-reduced-motion下取消过渡。打印和服务端PDF保持白底。存储禁用时仍可在本次会话切换。

## 实现边界

拟扩展appearance.ts/context及AppearanceSettings，新增受data-view=concise约束的首页组件/样式与明暗主题token。App复用同一任务/数据状态；正常版继续使用原组件树，不维护第二套分析请求。

新首页布局只在concise启用，公共主题token只使用现有light/dark解析结果，不增加palette属性。保留normal旧截图基线，以防一个全局CSS选择器改变正常版。

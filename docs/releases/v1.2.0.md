Lagent 1.2.0 把指挥台从「能派活」推进到「能长期协作」：工单之外补齐了例行任务、团队房间、项目库同步、MCP 连接、实时窗口观察、IM 审批与用量告警。

## 下载与使用

下载 **Lagent-Setup-1.2.0-x64.exe**，双击安装，支持 Windows 10/11 x64，无需另装 Node.js。桌面客户端既可连接本机服务 `http://127.0.0.1:3001`，也可连接管理员部署的 HTTPS 账号服务。

## 新增

- 工作操作面板：集中管理例行任务、团队房间、项目库同步、MCP 连接与用量。
- 例行任务支持间隔、每日、手动、Webhook、Git 提交和文件变化触发；文件路径限制在项目目录内，越界或敏感路径直接拒绝。
- 窗口实时观察：只保留内存中的最近一帧，检测到支付、密码、验证码等敏感窗口标题立即暂停采集。
- IM 通知与远程审批：Webhook 地址只存不回显，审批链接带签名、24 小时有效且只能使用一次。容器部署可直接沿用 `PUBLIC_URL` 生成链接。
- 模型供应商池与故障转移、会话用量与预算告警、项目数据备份。
- WorkBuddy 桌面端执行器：通过调试端口派发任务、等待消息帧完成并接收回复，未运行时自动拉起。
- 版本号统一从 `package.json` 读取，运行时接口、对外 User-Agent 与备份元数据保持一致。
